# OctoAcme Project Management Docs

A guide to OctoAcme's project management processes and the documents that support them.

## Process Summary

OctoAcme manages work through an iterative lifecycle: initiate and validate an idea, plan scope and delivery, execute and track progress, release and verify changes, and then capture lessons through retrospectives. Teams define outcomes and success measures, maintain prioritized backlogs and milestones, identify risks and dependencies, communicate status regularly, and use reviews, testing, and feedback to support reliable delivery and continuous improvement.

## How to Use This Collection

Use these documents together to move from idea to delivery with clear ownership, measurable outcomes, structured planning, and a repeatable communication rhythm. Each doc provides a focused guide for a stage of the project lifecycle while staying aligned with the broader OctoAcme operating model.
